# ABC_company_details
Data analysis and viualization for abc_company
This project is a comprehensive analysis of employee data for ABC Company, based on a dataset containing 458 rows and 9 columns.

# Objectives
- Preprocess and clean the data
- Analyze employee distribution, age patterns, salary trends, and team/position-based insights
- Visualize results clearly
- Summarize key insights and findings

# Preprocessing
- The `Height` column was replaced with random integers between 150 cm and 180 cm to ensure consistency and realism.
- Missing values in `Salary` were handled for correlation analysis.

# Analysis Tasks
- **Team Distribution**: Count and percentage split of employees per team
- **Position Segregation**: Grouping of employees by position title
- **Age Analysis**: Predominant age group identified using median/mode
- **Salary Insights**: Highest salary expenditure by team and by position
- **Correlation**: Between age and salary

# Visualizations
- Bar plots for team distribution and position segregation
- Age group histogram
- Salary expenditure bar charts by team and position
- Scatter plot for age vs. salary

# Key Insights
- The most common team and position were identified.
- The 26–30 age group is the most represented.
- Strong patterns emerged in salary allocation across roles.
- moderate correlation observed between age and salary.
